Install once. Upgrade in place.

Symlinked by default — re-running is always safe, and nothing this installer didn't create ever gets overwritten.

  1. 1.0

    Clone.

    Anywhere on disk — ~/agentkit is just the convention.

    git clone https://github.com/jthiruveedula/agentkit.git ~/agentkit
  2. 2.0

    Install.

    Symlinks into every tool you name — omit --tools for all four.

    cd ~/agentkit && ./install.sh --tools=claude,cursor
  3. 3.0

    Verify.

    Confirms the installed version and checks for a newer release.

    ./install.sh version
  4. 4.0

    Stay updated.

    Pulls the latest release and re-links with your last-used --tools — prunes anything removed upstream.

    ./install.sh upgrade

Seven skills, authored once.

Each is a canonical SKILL.md, transpiled to all four tool formats by scripts/build.py — never hand-copied.

prompt-enhancer

Classifies a raw prompt's intent (9 categories, deterministic scorer) and rewrites it using that intent's pattern.

v0.1.0 · flagship

skill-forge

Scaffolds a new compliant skill — SKILL.md, reference/scripts/tests, a golden test stub — from a one-line description.

v0.1.0

daily-standup

Summarizes commits, closed PRs, and open threads since your last standup into a 3-line update.

v0.1.0

pr-review

Reviews a pull request for correctness bugs and scope creep, posting inline findings.

v0.1.0

debug-loop

Runs a hypothesize-test-narrow loop on a failing test or crash until root cause is found.

v0.1.0

spec-writer

Turns a rough idea into a short spec — problem, scope, non-goals, acceptance criteria.

v0.1.0

meeting-to-actions
