01Install

Install once. Upgrade in place.

Pick whichever channel already exists on the target machine — all delegate to the same install.sh. Symlinked by default — re-running is always safe, and nothing this installer didn't create ever gets overwritten.

git clone https://github.com/jthiruveedula/agentkit.git ~/agentkit && cd ~/agentkit && ./install.sh
git clone https://github.com/jthiruveedula/agentkit.git $HOME\agentkit cd $HOME\agentkit; .\install.ps1
npx github:jthiruveedula/agentkit
uvx --from git+https://github.com/jthiruveedula/agentkit agentkit
git clone https://github.com/jthiruveedula/agentkit.git ~/agentkit && cd ~/agentkit && make install

Documented channels, per the README — the clone + install.sh path is the reference; npx/uvx/make all delegate to the same installer.

Verify.

Confirms the installed version and checks for a newer release.

./install.sh version

Stay updated.

Pulls the latest release and re-links with your last-used --tools — prunes anything removed upstream.

./install.sh upgrade

Add external sources.

Fetches every pinned external skill source in the same command — one line sets up native and external skills on a brand-new machine.

./install.sh --with-external
