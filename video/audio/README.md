# Music bed

`tracks/prompt-analytics.wav` is muxed into the site video by `../prompt-analytics/encode.sh`.

Generated with AudioCraft MusicGen (`facebook/musicgen-small`, CPU, 30s windows extended by continuation), prompt:
"calm minimal ambient electronic, soft pulsing synth pads, light tech documentary underscore, no vocals, 90 bpm".
